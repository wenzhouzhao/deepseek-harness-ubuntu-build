## 安装

```sh
sudo apt install ./deepseek-harness-0.2.2-rc.5-linux-amd64-unsigned.deb

# 可选：把应用目录交给当前用户，便于 dsh-purge 等插件解包宿主
sudo chown -R "$(id -u):$(id -g)" "/opt/DeepSeek Harness"

# 验证
dsh --version
```

安装后请完全退出并重新打开 DeepSeek Harness。`~/.dsh`（会话、profile、插件）
不受安装/升级影响。

## 从 rc.4 升级的注意事项

- 宿主 0.2.2-rc.2+ 要求 WebServer 路由显式准入；若侧边栏、Agent Teams 出现
  400 或 WebSocket 握手失败，执行：

  ```sh
  bash plugin-patch/patch-plugin-auth.sh
  bash scripts/restart-dsh.sh
  ```

- dsh-purge 的补丁表若在 rc.5 上出现漂移，执行
  `bash plugin-patch/reapply-plugin-patch.sh` 后重新在面板应用。
- profile 中不要保留旧版 `@deepseek-ai/*` 包（例如 0.2.1-rc.3）；它们会遮蔽
  宿主服务，导致 `sessionController` 不可用。
